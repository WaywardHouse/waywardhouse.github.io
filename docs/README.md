# Wayward House — hub site

Astro static build deployed to **GitHub Pages** as the WaywardHouse org site. See [HOSTING.md](HOSTING.md) for how publishing works and the one-time migration steps. Hub for essays, the System Signals newsletter, and a Library of long-form books that live as separate Quarto deploys under `wayward.house/<slug>/`.

## Stack

- **Astro 5** (`output: 'static'`) — content collections, MDX, image optimization
- **GitHub Pages** via GitHub Actions for the site (free, no per-request billing)
- **Cloudflare Worker** (`worker/`) for `/api/*` only: Pepper, subscribe/confirm/unsubscribe
- **Pagefind** for client-side search (built into the navbar; press `/` or click Search)
- **Satori + resvg** for build-time OG image generation
- **`@astrojs/cloudflare`** adapter is included so you can opt into hybrid SSR (e.g. dynamic OG endpoints) without re-tooling

## Hero variants

The home page has three hero variants — `cinematic` (default), `editorial`, `document`. Switch via `?hero=editorial` or use the in-page switcher (visible on localhost or with `?preview=1`).

## Image manifest + `<WhImage>`

`src/content/images.ts` is the single source of truth for every photograph. To add an image:

1. Add an entry to `library` with id, pillar, slug, coords, author, mood, default treatment, aspect.
2. Either keep `unsplash:` for hotlinking during design, or remove it and drop the file at `public/images/<pillar-lowercase>/<slug>.jpg`.
3. Reference it anywhere with `<WhImage id="geo-02" treatment="duotone" ratio="21/9" />`.

Treatments are CSS-only: `raw`, `warm` (graded + grain), `duotone` (grayscale + multiply accent), `caption-bar` (light filter + amber coords bar + filename + WH mark).

## Books, essays and signals — routing

- **Books** are separate public repos, each deployed to GitHub Pages. This repo is the org site that owns `wayward.house`, so GitHub serves any org repo with Pages enabled at `wayward.house/<repo-name>/`. **The repo name is the URL slug** (`mathematics` → `/mathematics/`).
- **Essays and signals** (`wh-essays`, `wh-signals`) are rendered by this repo's build and folded into `dist/essays/` and `dist/signals/` by `scripts/assemble-site.mjs`. The hub keeps its own `/essays/` and `/signals/` listing pages and RSS feeds.
- **Old URLs** (`/articles/*`, `/learn/<book>/`, `/essays/<slug>/` with a trailing slash) get static redirect pages from the same script, since GitHub Pages has no `_redirects`.

## Search

Pagefind is generated by `pagefind --site dist` in `npm run build`. The trigger lives in the header; the UI is loaded lazily on first activation. Press `/` from anywhere to open it.

## OG images

`scripts/generate-og.mjs` runs after `astro build` (part of `npm run build`). It walks `src/content/essays/`, renders an SVG per essay with Satori, rasterizes with resvg, and writes to `dist/og/essays/<slug>.png`. Layout.astro emits a canonical `og:image` URL pointing at that path.

> Drop the four required TTFs into `public/fonts/`:
> `BarlowCondensed-Regular.ttf`, `BarlowCondensed-Bold.ttf`, `IBMPlexMono-Regular.ttf`. The script no-ops with a warning if they're missing.

## Deploy

### Local
```bash
npm install
npm run dev          # localhost:4321
```

`npm run build` folds in `../wh-essays/_site` and `../wh-signals/_site` if you've rendered them locally; otherwise it skips them with a warning.

### Site (GitHub Pages)
`.github/workflows/pages.yml` runs on every push to `main`, daily, on manual dispatch, and when `wh-essays`/`wh-signals` send a `subsite-updated` dispatch. It renders both Quarto sub-sites, builds Astro, and deploys. No secrets required.

### API (Cloudflare Worker)
`.github/workflows/api.yml` deploys `worker/` when files under it change. Secrets: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`. Manual alternative: `npm run api:deploy`. The Resend key is a Worker secret: `npx wrangler secret put RESEND_API_KEY --config worker/wrangler.toml`.

Keep the Cloudflare account on the **Workers Free** plan. Hitting a daily limit then makes `/api/*` error until midnight UTC; it can never produce a bill.
